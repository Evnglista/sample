# BYTEFORGE PC

A static HTML/CSS website for a fictional computer-parts store. The website files are in [`BYTEFORGE-PC/`](./BYTEFORGE-PC/).

## Deploy with GitHub Pages

This repository includes a GitHub Actions workflow that publishes the `BYTEFORGE-PC` folder to GitHub Pages when changes are pushed to the `main` branch.

1. Push this repository to GitHub using the `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. Push a commit to `main`, or run the **Deploy to GitHub Pages** workflow from the **Actions** tab.
4. Open the Pages URL shown in the workflow's deployment summary.

The site is plain HTML and CSS and does not require a build step.
